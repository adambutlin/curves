## Domain primer for the implementer

You are working on a UK rates research repo. Three things you need to know:

1. **The decomposition.** A nominal government bond yield splits into the expected average future short rate plus a term premium: `y = E[r] + TP`. The Adrian–Crump–Moench (ACM) model in `src/giltcurve/premium/acm.py` produces that split. It is already validated against the New York Fed's published series and is **frozen** — do not modify it, do not "improve" it.

2. **The epistemic rule.** ACM produces a *latent* decomposition. It does not tell you *why* the term premium moved. Anything about fiscal risk, supply, or positioning is an *interpretation*, never a model output. This distinction is enforced in code by `episode/tags.py`, not left to discipline.

3. **Units.** All curve data in this repo is **decimal** (0.0435 = 4.35%), continuously compounded. Yield *changes* are reported in **basis points** (1bp = 0.0001 = 1e-4). BoE and Fed source files are in percent and the loaders divide by 100. FRED is the exception — see Task 5.

Rates jargon you will meet: *tenor/maturity* (years to maturity), *front end* (short maturities, ~2y), *long end* (20y+), *OIS* (overnight index swap — a market-implied path of the central bank policy rate), *breakeven* (nominal yield minus real yield ≈ inflation compensation), *DV01* (money change in value per 1bp yield move).

```python
"""Cached HTTP fetch with a curl fallback.

Python's ``urllib`` times out connecting to the Bank of England CDN in some
sandboxed environments while ``curl`` succeeds on the identical URL (verified
2026-08-20). Every ingest adaptor therefore goes through :func:`fetch`, which
tries ``urllib`` first and falls back to the ``curl`` binary.

Downloads are written to a temporary sibling and moved into place only on
success, so a failed fetch never leaves a truncated file that a later cached
read would happily return -- this covers both a mid-download error and a
200 response with an empty body, which is plausible for the very BoE CDN
that already misbehaves here.
"""
from __future__ import annotations

import subprocess
import urllib.request
from pathlib import Path

USER_AGENT = "giltcurve-research/0.1"
DEFAULT_TIMEOUT = 120


def _urllib_download(url: str, dest: Path, timeout: int) -> None:
    req = urllib.request.Request(url, headers={"User-Agent": USER_AGENT})
    with urllib.request.urlopen(req, timeout=timeout) as resp:
        dest.write_bytes(resp.read())


def _curl_download(url: str, dest: Path, timeout: int) -> None:
    proc = subprocess.run(
        ["curl", "-sSLf", "--max-time", str(timeout), "-A", USER_AGENT, "-o", str(dest), url],
        capture_output=True, text=True,
    )
    if proc.returncode != 0:
        raise RuntimeError(f"curl exited {proc.returncode} for {url}: {proc.stderr.strip()}")


def fetch(url: str, dest: str | Path, *, force: bool = False, timeout: int = DEFAULT_TIMEOUT) -> Path:
    """Download ``url`` to ``dest`` (cached unless ``force``) and return its path.

    Returns the path rather than the bytes so callers that hand the file to
    ``zipfile`` or ``read_excel`` -- which is most of them, and the ones
    fetching the largest archives -- do not pay for a pointless full read of a
    file that was just written. Callers wanting the content call
    ``.read_bytes()`` / ``.read_text()``.
    """
    dest = Path(dest)
    if dest.exists() and not force:
        return dest

    dest.parent.mkdir(parents=True, exist_ok=True)
    tmp = dest.with_suffix(dest.suffix + ".part")
    try:
        try:
            _urllib_download(url, tmp, timeout)
        except Exception:
            _curl_download(url, tmp, timeout)
        if tmp.stat().st_size == 0:
            raise RuntimeError(f"downloaded 0 bytes for {url}")
    except Exception:
        tmp.unlink(missing_ok=True)
        raise
    tmp.replace(dest)
    return dest
```

## Task 3: Generalised BoE curve loader

`ingest/boe_gilt.py` handles the nominal archive. The study needs all four — nominal, real, inflation and OIS — which share a sheet layout and differ only in archive name, workbook name pattern and sheet aliases. Generalise rather than copy-paste three times.

Verified facts you can rely on (checked against the live site 2026-08-20):
- Archives live at `https://www.bankofengland.co.uk/-/media/boe/files/statistics/yield-curves/<name>.zip` where `<name>` is one of `glcnominalddata`, `glcrealddata`, `glcinflationddata`, `oisddata`.
- The history zips are updated roughly fortnightly (they held data to end-July on 2026-08-20); `latest-yield-curve-data.zip` carries the current month and closes the gap. You need both.
- Sheet naming is **much** messier than a single alias tuple can express. Verified across all 30 workbooks on 2026-08-21:

  | kind | vintage | spot sheet name |
  |---|---|---|
  | nominal | pre-2005 | `4. nominal spot curve` |
  | nominal | 2005+ | `4. spot curve` |
  | real | pre-2005 | `4.  real spot curve` — **double space** |
  | real | 2005+ | `4. spot curve` |
  | inflation | pre-2005 | `4.  inf spot curve` — **double space, and "inf" not "inflation"** |
  | inflation | 2005+ | `4. spot curve` |
  | ois | 2009-2015 | `2. spot curve` — **sheet 2, that vintage has no short-end split** |
  | ois | 2016+ | `4. spot curve` |

  So the sheet number varies, the qualifier varies, and two vintages have a double space. A literal alias list is the wrong shape; resolve by whitespace-normalising and matching `^\d+\.\s+(?:nominal\s+|real\s+|inf\s+)?spot curve$`. That pattern matches exactly one sheet in every one of the 30 workbooks and never matches the `3. ... spot, short end` sheets, which are a different (short-end-only) curve.
- Values are in percent; `parse_ois_sheet` already divides by 100.

```python
The BoE publishes nominal gilt, real gilt, implied-inflation and SONIA OIS
curves as separate zip archives that share one sheet layout, so a single
loader parameterised by ``kind`` covers all four. This supersedes the
nominal-only ``ingest/boe_gilt.py``, whose public functions still work.

Each kind needs two downloads: the multi-decade history archive (updated
roughly fortnightly) and ``latest-yield-curve-data.zip`` (the current month).
Merging both is what gets you data right up to yesterday.

Quirks verified against the live site (2026-08-20/21):
  * ``latest-yield-curve-data.zip`` is usually flat but is occasionally served
    with an inner zip; ``_extract_member`` handles both.
  * The spot-curve sheet name varies by kind AND by vintage, not just by the
    nominal/pre-2005 split documented in ``boe_gilt.py``. Verified sheet names
    across every history workbook and the current-month workbook:
      - nominal:   "4. nominal spot curve" (pre-2005) / "4. spot curve" (2005+)
      - real:      "4.  real spot curve"   (pre-2005, note the double space)
                   / "4. spot curve" (2005+)
      - inflation: "4.  inf spot curve"    (pre-2005, double space)
                   / "4. spot curve" (2005+)
      - ois:       "2. spot curve" (2009-2015; this vintage has no short-end
                   split, only "1. fwd curve" / "2. spot curve") / "4. spot
                   curve" (2016+)
    Rather than hardcode five brittle literal strings (one of which relies on
    reproducing an inconsistent double space), ``_resolve_spot_sheet`` matches
    sheet names by pattern: whitespace-normalise, then accept ``"<n>. [prefix
    ]spot curve"`` for any leading sheet number and optional nominal/real/inf
    prefix. This is derived from live inspection of every workbook, not a
    guess.
  * Values are in percent; ``parse_ois_sheet`` converts to decimals.
"""
from __future__ import annotations

import io
import re
import zipfile
from dataclasses import dataclass
from pathlib import Path

import pandas as pd

from giltcurve.ingest._http import fetch
from giltcurve.ingest.boe import parse_ois_sheet

BASE_URL = "https://www.bankofengland.co.uk/-/media/boe/files/statistics/yield-curves"
LATEST_ARCHIVE = "latest-yield-curve-data.zip"

# Matches "4. spot curve", "4. nominal spot curve", "4.  real spot curve"
# (any run of whitespace), "4.  inf spot curve", "2. spot curve" (the OIS
# 2009-2015 vintage, which has no short-end sheets and numbers spot curve 2
# rather than 4) -- every spot-curve sheet name observed across all four
# kinds and all vintages, live-verified rather than assumed.
_SPOT_SHEET_RE = re.compile(r"^\d+\.\s+(?:nominal\s+|real\s+|inf\s+)?spot curve$")


@dataclass(frozen=True)
class CurveSpec:
    archive: str              # history zip file name
    workbook_token: str       # substring identifying this kind's workbooks
    current_month_member: str  # member name inside LATEST_ARCHIVE


KIND_SPEC = {
    "nominal": CurveSpec("glcnominalddata.zip", "Nominal",
                         "GLC Nominal daily data current month.xlsx"),
    "real": CurveSpec("glcrealddata.zip", "Real",
                      "GLC Real daily data current month.xlsx"),
    "inflation": CurveSpec("glcinflationddata.zip", "Inflation",
                           "GLC Inflation daily data current month.xlsx"),
    "ois": CurveSpec("oisddata.zip", "OIS",
                     "OIS daily data current month.xlsx"),
}
CURVE_KINDS = tuple(KIND_SPEC)


def _spec(kind: str) -> CurveSpec:
    try:
        return KIND_SPEC[kind]
    except KeyError:
        raise ValueError(
            f"unknown curve kind {kind!r}; expected one of {CURVE_KINDS}"
        ) from None


def _extract_member(zip_path: Path, dest_dir: Path, predicate) -> list[Path]:
    """Extract members matching ``predicate``, descending into an inner zip if needed."""
    out = []
    with zipfile.ZipFile(zip_path) as zf:
        names = [n for n in zf.namelist() if predicate(n)]
        for name in names:
            zf.extract(name, dest_dir)
            out.append(dest_dir / name)
        if out:
            return out
        for inner in (n for n in zf.namelist() if n.endswith(".zip")):
            with zipfile.ZipFile(io.BytesIO(zf.read(inner))) as zf2:
                for name in (n for n in zf2.namelist() if predicate(n)):
                    zf2.extract(name, dest_dir)
                    out.append(dest_dir / name)
    return out


def download_history(kind: str, data_dir="data/raw", force: bool = False) -> list[Path]:
    """Download + extract the multi-decade history archive for ``kind``."""
    spec = _spec(kind)
    data_dir = Path(data_dir)
    zip_path = data_dir / spec.archive
    fetch(f"{BASE_URL}/{spec.archive}", zip_path, force=force)
    return _extract_member(
        zip_path, data_dir,
        lambda n: spec.workbook_token in n and n.endswith(".xlsx"),
    )


def download_current_month(kind: str, data_dir="data/raw", force: bool = False) -> list[Path]:
    """Download + extract the current-month workbook for ``kind``."""
    spec = _spec(kind)
    data_dir = Path(data_dir)
    zip_path = data_dir / LATEST_ARCHIVE
    # Always refresh: this archive is the whole point of being current.
    fetch(f"{BASE_URL}/{LATEST_ARCHIVE}", zip_path, force=True)
    return _extract_member(
        zip_path, data_dir,
        lambda n: n.endswith(spec.current_month_member),
    )


def _resolve_spot_sheet(path: Path, sheet: str | None) -> str:
    if sheet is not None:
        return sheet
    names = pd.ExcelFile(path).sheet_names
    for name in names:
        normalized = re.sub(r"\s+", " ", name.strip())
        if _SPOT_SHEET_RE.match(normalized):
            return name
    raise ValueError(f"no spot-curve sheet found in {path}; sheets={names}")


def merge_panels(history: pd.DataFrame, current: pd.DataFrame) -> pd.DataFrame:
    """Concatenate, letting ``current`` win on shared dates, then drop empty rows."""
    panel = pd.concat([history, current]).sort_index()
    panel = panel[~panel.index.duplicated(keep="last")]
    return panel.dropna(how="all")


def load_curve(kind: str, data_dir="data/raw", sheet: str | None = None,
               force: bool = False) -> pd.DataFrame:
    """Full daily panel for ``kind``: index=date, columns=maturity(years), decimal."""
    spec = _spec(kind)
    hist_files = download_history(kind, data_dir, force=force)
    cur_files = download_current_month(kind, data_dir, force=force)
    if not hist_files:
        raise FileNotFoundError(f"no {spec.workbook_token!r} workbooks in {spec.archive}")

    def _read(paths):
        frames = [parse_ois_sheet(p, _resolve_spot_sheet(p, sheet)) for p in paths]
        return pd.concat(frames).sort_index() if frames else pd.DataFrame()

    return merge_panels(_read(sorted(hist_files)), _read(cur_files))
```

```python
"""Bundesbank daily Svensson-fitted Bund zero yields (the German control leg).

The Bundesbank time-series API serves one CSV per residual maturity. The file
opens with a metadata preamble whose length is not contractually stable, so
dated rows are located by pattern rather than by a hard-coded skiprows.

Values are in percent; this module returns decimals to match the rest of the
repo. Source: https://api.statistiken.bundesbank.de/rest/download/BBSIS/
"""
from __future__ import annotations

import re
from pathlib import Path

import pandas as pd

from giltcurve.ingest._http import fetch

BASE_URL = "https://api.statistiken.bundesbank.de/rest/download/BBSIS"
DEFAULT_TENORS = (1, 2, 5, 10, 30)
_DATED_ROW = re.compile(r"^(\d{4}-\d{2}-\d{2}),([^,]*)")


def series_code(tenor_years: int) -> str:
    """BBSIS series code for a residual maturity in whole years."""
    return f"D.I.ZST.ZI.EUR.S1311.B.A604.R{int(tenor_years):02d}XX.R.A.A._Z._Z.A"


def parse_series_csv(text: str) -> pd.Series:
    """Parse one BBSIS CSV into a dated Series of decimal yields."""
    dates, values = [], []
    for line in text.splitlines():
        m = _DATED_ROW.match(line.strip())
        if not m:
            continue
        raw = m.group(2).strip()
        if not raw:
            continue          # published date with no observation (holiday)
        dates.append(pd.Timestamp(m.group(1)))
        values.append(float(raw) / 100.0)
    return pd.Series(values, index=pd.DatetimeIndex(dates)).sort_index()


def load_bund_panel(tenors=DEFAULT_TENORS, data_dir="data/raw",
                    force: bool = False) -> pd.DataFrame:
    """Daily Bund zero yields: index=date, columns=maturity(years), decimal."""
    data_dir = Path(data_dir)
    cols = {}
    for t in tenors:
        code = series_code(t)
        path = fetch(f"{BASE_URL}/{code}?format=csv&lang=en",
                     data_dir / f"bbsis_{code}.csv", force=force)
        cols[float(t)] = parse_series_csv(path.read_text("utf-8", "replace"))
    return pd.DataFrame(cols).sort_index()
```

```python
"""FRED daily series, no API key required.

``fred.stlouisfed.org/graph/fredgraph.csv?id=<series>`` serves plain CSV with
missing observations coded as the literal string ``"."``.

Units differ across series and are NOT normalised here: Brent is USD/barrel,
DEXUSUK is USD per GBP, DGS10/DGS30/T10YIE are percent. Each entry declares
whether it is a percent series; use :func:`as_decimal` to convert the ones
that are. A blanket division by 100 would silently corrupt Brent and FX.
"""
from __future__ import annotations

import io
from dataclasses import dataclass
from pathlib import Path

import pandas as pd

from giltcurve.ingest._http import fetch

BASE_URL = "https://fred.stlouisfed.org/graph/fredgraph.csv"


@dataclass(frozen=True)
class FredSeries:
    series_id: str
    percent: bool
    description: str


SERIES = {
    "brent": FredSeries("DCOILBRENTEU", False, "Brent crude, USD/bbl"),
    "gbpusd": FredSeries("DEXUSUK", False, "USD per GBP"),
    "ust10": FredSeries("DGS10", True, "US 10y Treasury constant maturity"),
    "ust30": FredSeries("DGS30", True, "US 30y Treasury constant maturity"),
    "us_be10": FredSeries("T10YIE", True, "US 10y breakeven inflation"),
}


def parse_series_csv(text: str) -> pd.Series:
    """Parse a fredgraph CSV into a dated Series in published units."""
    df = pd.read_csv(io.StringIO(text), na_values=["."])
    date_col, value_col = df.columns[0], df.columns[1]
    df[date_col] = pd.to_datetime(df[date_col], errors="coerce")
    df[value_col] = pd.to_numeric(df[value_col], errors="coerce")
    df = df.dropna(subset=[date_col, value_col])
    return pd.Series(df[value_col].to_numpy(float),
                     index=pd.DatetimeIndex(df[date_col])).sort_index()


def as_decimal(series: pd.Series, name: str) -> pd.Series:
    """Divide by 100 iff ``name`` is a percent series; otherwise pass through."""
    return series / 100.0 if SERIES[name].percent else series


def load_series(name: str, data_dir="data/raw", force: bool = False) -> pd.Series:
    """Load one named series in its published units."""
    spec = SERIES[name]
    path = fetch(f"{BASE_URL}?id={spec.series_id}",
                 Path(data_dir) / f"fred_{spec.series_id}.csv", force=force)
    return parse_series_csv(path.read_text("utf-8", "replace"))


def load_frame(names=tuple(SERIES), data_dir="data/raw",
               force: bool = False) -> pd.DataFrame:
    """Load several named series into one frame (published units, outer-joined)."""
    return pd.DataFrame({n: load_series(n, data_dir, force) for n in names}).sort_index()
```

```python
"""The epistemic contract, enforced as a required column.

The study's central rule is that three categories never blur:

  OBSERVED         directly measured -- yields, OIS, breakevens, energy, FX
  MODEL_IMPLIED    latent ACM output -- expected-rate component, term premium
  INTERPRETATION   economic narrative -- fiscal risk, supply, positioning

ACM produces a latent decomposition; it does NOT identify why a term premium
moved. Attributing a term-premium move to fiscal risk is an interpretation, and
must be labelled as one. This module makes that structural: every frame the
episode package emits carries a validated ``tag`` column, so an interpretation
cannot reach a figure or a table without saying what it is.
"""
from __future__ import annotations

from enum import Enum

import pandas as pd


class Tag(str, Enum):
    OBSERVED = "OBSERVED"
    MODEL_IMPLIED = "MODEL_IMPLIED"
    INTERPRETATION = "INTERPRETATION"


def _coerce(tag) -> Tag:
    try:
        return Tag(tag)
    except ValueError:
        raise ValueError(
            f"{tag!r} is not a valid epistemic tag; expected one of "
            f"{[t.value for t in Tag]}"
        ) from None


def tagged(rows, tag) -> pd.DataFrame:
    """Build a DataFrame from ``rows`` with a validated ``tag`` column."""
    tag = _coerce(tag)
    rows = list(rows)
    if any("tag" in r for r in rows):
        raise ValueError(
            "rows already carry a 'tag'; re-tagging would hide the original "
            "epistemic category"
        )
    df = pd.DataFrame.from_records(rows)
    df["tag"] = tag.value
    return df


def require_tags(df: pd.DataFrame) -> None:
    """Raise unless ``df`` carries a ``tag`` column of valid tag values."""
    if "tag" not in df.columns:
        raise ValueError("frame is missing the required 'tag' column")
    valid = {t.value for t in Tag}
    bad = set(df["tag"].unique()) - valid
    if bad:
        raise ValueError(f"unknown tag value(s) {sorted(bad)}; expected {sorted(valid)}")
```

```python
"""Event-window algebra over the frozen ACM decomposition.

For a pre-specified window and a set of tenors, split the observed yield change
into its expected-rate and term-premium contributions:

    dy = dE[r] + dTP

reported in basis points. Everything here is arithmetic on the decomposed panel
produced by ``premium/acm.py::decompose``; no estimation happens in this module.

Window endpoints fall back to the last close at or before the requested date,
because pre-specified dates can land on non-trading days and silently shifting
to the NEXT close would let a window swallow an event it was meant to exclude.
"""
from __future__ import annotations

import numpy as np
import pandas as pd

from giltcurve.episode.chronology import Window
from giltcurve.episode.tags import Tag, tagged

BP = 1e4


def _asof_row(panel: pd.DataFrame, when) -> pd.Series:
    """The last row at or before ``when`` for one (currency, maturity) series."""
    stamp = pd.Timestamp(when)
    eligible = panel[panel["date"] <= stamp]
    if eligible.empty:
        raise ValueError(f"no observation at or before {stamp:%Y-%m-%d}")
    return eligible.sort_values("date").iloc[-1]


def decompose_window(panel: pd.DataFrame, win: Window, tenors=(2.0, 5.0, 10.0),
                     currency: str = "GBP") -> pd.DataFrame:
    """dy = dE[r] + dTP in basis points, per tenor, for one window."""
    ccy = panel[panel["currency"] == currency]
    rows = []
    for m in tenors:
        at_tenor = ccy[ccy["maturity"] == float(m)]
        if at_tenor.empty:
            raise ValueError(f"maturity {float(m)} not in panel for {currency}")
        a = _asof_row(at_tenor, win.start)
        b = _asof_row(at_tenor, win.end)
        rows.append({
            "window": win.name,
            "currency": currency,
            "maturity": float(m),
            "start": a["date"].date(),
            "end": b["date"].date(),
            "d_yield_bp": (b["observed"] - a["observed"]) * BP,
            "d_expected_bp": (b["expected_rate"] - a["expected_rate"]) * BP,
            "d_term_premium_bp": (b["term_premium"] - a["term_premium"]) * BP,
            "confounded": win.confounded,
        })
    return tagged(rows, Tag.MODEL_IMPLIED)


def additivity_check(df: pd.DataFrame, atol_bp: float = 0.05) -> None:
    """Raise unless dy equals dE[r] + dTP within ``atol_bp`` on every row.

    ACM's fitted yield, not the observed yield, is what decomposes exactly, so a
    small fitting residual is expected; a large one means the panel was built
    wrong.
    """
    resid = df["d_yield_bp"] - (df["d_expected_bp"] + df["d_term_premium_bp"])
    worst = float(np.abs(resid).max())
    if worst > atol_bp:
        bad = df.loc[np.abs(resid) > atol_bp, ["window", "maturity"]]
        raise ValueError(
            f"d_yield_bp does not equal d_expected_bp + d_term_premium_bp "
            f"(worst residual {worst:.3f}bp > {atol_bp}bp) at:\n{bad.to_string(index=False)}"
        )
```

```python
def curve_asof(curve: pd.DataFrame, when, tenor: float) -> float:
    """Last available yield at or before ``when`` for one tenor of a raw panel.

    Public because the runner and the model-free long-end split both need it;
    reaching across a module boundary for a private name is how private names
    stop being private.
    """
    if float(tenor) not in set(curve.columns.astype(float)):
        raise ValueError(f"maturity {float(tenor)} not in curve panel")
    series = curve[float(tenor)].dropna()
    eligible = series[series.index <= pd.Timestamp(when)]
    if eligible.empty:
        raise ValueError(f"no observation at or before {pd.Timestamp(when):%Y-%m-%d}")
    return float(eligible.iloc[-1])


def cross_market(curves: dict, win: Window, tenors=(2.0, 5.0, 10.0),
                 base: str = "UK") -> pd.DataFrame:
    """Matched-maturity yield changes per market, plus differentials vs ``base``.

    ``curves`` maps a market label to a raw yield panel (index=date, columns=
    maturity in years, decimals). Output is OBSERVED: these are measured yields,
    not model output, and the differential is arithmetic on them.

    A residual is NOT evidence of "UK risk" on its own. The three markets are
    fitted by three different methodologies (BoE Anderson-Sleath, Fed GSW,
    Bundesbank Svensson), so score the differential against its own history via
    ``placebo_distribution`` before reading anything into it.
    """
    if base not in curves:
        raise ValueError(f"base market {base!r} not provided; have {sorted(curves)}")
    rows = []
    for m in tenors:
        moves = {
            label: (curve_asof(c, win.end, m) - curve_asof(c, win.start, m)) * BP
            for label, c in curves.items()
        }
        for label, move in moves.items():
            rows.append({
                "window": win.name,
                "market": label,
                "maturity": float(m),
                "d_yield_bp": move,
                "d_vs_base_bp": moves[base] - move,
                "base": base,
            })
    return tagged(rows, Tag.OBSERVED)


def placebo_distribution(curve: pd.DataFrame, tenor: float, length_days: int,
                         n: int = 200, seed: int = 0) -> dict:
    """Quantiles of |yield change| over ``n`` random pre-shock windows.

    Turns "the 10y moved 77bp" into "the 10y moved 77bp, versus a 95th
    percentile of X bp for a window of this length in the year before the
    shock" -- which is the only version of the sentence a PM should accept.
    """
    from giltcurve.episode.chronology import placebo_windows

    moves = []
    for w in placebo_windows(length_days=length_days, n=n, seed=seed):
        try:
            a = curve_asof(curve, w.start, tenor)
            b = curve_asof(curve, w.end, tenor)
        except ValueError:
            continue
        moves.append(abs(b - a) * BP)
    if not moves:
        raise ValueError("no placebo window could be evaluated on this curve")
    arr = np.asarray(moves, float)
    return {
        "tenor": float(tenor),
        "length_days": length_days,
        "n": len(arr),
        "p50_abs_bp": float(np.percentile(arr, 50)),
        "p90_abs_bp": float(np.percentile(arr, 90)),
        "p95_abs_bp": float(np.percentile(arr, 95)),
        "_samples_bp": arr,
    }


def placebo_percentile(move_bp: float, dist: dict) -> float:
    """Fraction of placebo windows whose absolute move was smaller than ``move_bp``."""
    arr = dist["_samples_bp"]
    return float((arr < abs(move_bp)).mean())
```

```python
    daily = decompose(result, panel, maturities=list(TENORS))
    return result, daily


def event_study(daily: pd.DataFrame) -> pd.DataFrame:
    frames = [decompose_window(daily, w, tenors=TENORS) for w in WINDOWS]
    out = pd.concat(frames, ignore_index=True)
    additivity_check(out)
    require_tags(out)
    return out


def baseline_sensitivity(daily: pd.DataFrame) -> pd.DataFrame:
    """Recompute the cumulative window from each alternative baseline."""
    frames = []
    for base in BASELINE_SENSITIVITY:
        w = Window(f"W7@{base:%d%b}", base, ASOF, "baseline sensitivity")
        frames.append(decompose_window(daily, w, tenors=TENORS))
    return pd.concat(frames, ignore_index=True)


def long_end_model_free(nominal: pd.DataFrame, inflation: pd.DataFrame,
                        real: pd.DataFrame, tenor: float = 30.0) -> pd.DataFrame:
    """30y nominal change = breakeven change + real change. No model involved.

    ACM stops at its validated 10y, so the long end -- where the selloff is
    largest -- is decomposed with an identity on three published BoE curves
    instead. Tagged OBSERVED, and unattackable on estimator grounds.
    """
    from giltcurve.episode.eventstudy import BP, curve_asof
    from giltcurve.episode.tags import Tag, tagged

    w = window("W7")
    rows = []
    for label, curve in (("nominal", nominal), ("breakeven", inflation), ("real", real)):
        try:
            move = (curve_asof(curve, w.end, tenor)
                    - curve_asof(curve, w.start, tenor)) * BP
        except ValueError as exc:
            print(f"  (skipping {label} at {tenor:.0f}y: {exc})")
            continue
        rows.append({"window": w.name, "maturity": tenor, "component": label,
                     "d_bp": move})
    return tagged(rows, Tag.OBSERVED)


def meeting_dated_path(ois: pd.DataFrame) -> None:
    """Implied Bank Rate at each MPC meeting, at the window endpoints.

    Spot OIS changes say the front end repriced; the meeting-dated path says
    WHICH meetings did the repricing, which is what an MPC-expectations story
    has to be consistent with. Depends on the reconciled calendar from Task 2 --
    a stale meeting list silently misattributes the path.
    """
    from giltcurve.curves.discount import DiscountCurve
    from giltcurve.policy.meeting_dated import implied_policy_path
    from giltcurve.policy.mpc import upcoming_mpc_dates

    w = window("W7")
    for when in (w.start, w.end):
        row = ois[ois.index <= pd.Timestamp(when)].iloc[-1].dropna()
        t = row.index.to_numpy(float)
        curve = DiscountCurve(t, np.exp(-row.to_numpy(float) * t), valuation_date=when)
        path = implied_policy_path(curve, upcoming_mpc_dates(when), when)
        head = path.head(6)
        legs = "  ".join(
            f"{r.window_end:%b%y} {r.implied_bank_rate * 100:.2f}%"
            for r in head.itertuples()
        )
        print(f"  {when:%Y-%m-%d}: {legs}")
        print(f"    cumulative to the 6th window: "
              f"{head['cum_change_bp'].iloc[-1]:+.0f}bp")
```

**If a number disagrees with the spec.** Spec §3 records what was measured on 2026-08-20. The pipeline is the source of truth; the spec is a regression target. A small drift is expected — BoE revises curves, and ACM parameters move as the estimation history extends. A large disagreement means something is miswired. Do not widen a tolerance to make a test pass without first understanding why it moved.

**If the conclusion flips.** If the refreshed data say the term premium dominates after all, that is a finding, not a bug. Write up what the data say. The spec's H1–H4 exist precisely so the answer is not predetermined — the study is set up to be able to reach a different conclusion than the one the design-time evidence pointed at.

**What not to do.** Do not modify `premium/acm.py`. Do not extend the ACM grid past 10y. Do not adjust a window to improve a result. Do not fit a threshold or a trading rule on the historical episodes. Do not let an interpretation into a figure without its tag.
